# LinguaBridge AI | Project website

A responsive, dependency-free website for **LinguaBridge AI**, an independent student-led EdTech project currently in the prototype phase.

**Official project homepage after publication:** https://linguabridge-ai.github.io/

## Publish using GitHub Pages

1. In the GitHub organization `LinguaBridge-AI`, create a **public** repository named `linguabridge-ai.github.io`.
2. Upload the files from this folder **into the repository root**: `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `README.md`.
3. Open the repository's **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
4. After publication, visit https://linguabridge-ai.github.io/.

The site deliberately describes Qwen TTS as a technology **under evaluation**, not a completed integration. It does not imply a registered business, a launched service, clients, usage metrics, or sponsorship by Alibaba Cloud.

## Customize

Edit `index.html` to update the roadmap and only add concrete claims once you have verified them. No paid hosting, packages, or external scripts are needed.
